# Contribuindo para o Hexa

Primeiramente, obrigado por dedicar seu tempo para contribuir!

## Como Contribuir

1.  **Faça um Fork** do projeto no GitHub.
2.  **Clone o projeto** para sua máquina local.
3.  **Crie uma branch** para sua funcionalidade ou correção de bug.
    ```bash
    git checkout -b feature/funcionalidade-incrivel
    ```
4.  **Faça o commit** das suas alterações com uma mensagem descritiva.
    ```bash
    git commit -m "feat: Adiciona funcionalidade incrível"
    ```
5.  **Envie (Push)** a branch para o seu fork.
    ```bash
    git push origin feature/funcionalidade-incrivel
    ```
6.  **Abra um Pull Request** no nosso repositório.

## Estilo de Código

- Utilizamos **TypeScript** e **React**.
- Por favor, garanta que seu código siga o estilo e convenções existentes.
- Use nomes de variáveis e funções significativos.

## Reportando Bugs

Se você encontrar um bug, por favor crie uma issue no GitHub descrevendo:
1.  O que você esperava que acontecesse.
2.  O que realmente aconteceu.
3.  Passos para reproduzir o problema.

Obrigado pela sua ajuda!
